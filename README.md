# SWE-Lego Website Redirect

This repository preserves the legacy GitHub Pages URL at <https://swe-lego.github.io/> after the organization moved from **SWE-Lego** to **LegoX**.

The website's source and primary deployment are maintained in [LegoX/swe-lego.github.io](https://github.com/LegoX/swe-lego.github.io). Visitors to the legacy URL are automatically redirected to the current website at <https://legox.github.io/swe-lego.github.io/>.
